# 小人物逆袭 0.27 · 首幕试玩记录

本次开放《月光宝盒》主题山寨的五波挑战，长棍、一棍开天和对应成长卡。其他职业、其他大招和后续电影场景尚未开放。电脑浏览器直接打开，无需安装 Unity。

已修复北墙外刷怪导致清场卡死、闪身动作引用丢失、回棍动作过早中断，以及部分攻击预警与伤害轮廓不一致。现在保留真实模型、手持武器和骨骼动作；怪物主动来袭并显示血条。

验证结果：

- Unity Editor：正常按钮开局，前10秒不移动也能自动攻击。随后以正常输入的自动策略完成五波、首领死亡、最终奖励及胜利结算；游戏内5分25秒，229击杀、7次成长、12次大招。没有直接补血、改属性、改关卡或强制胜利。单种子、单条大招路线通过。
- Chrome：中文起名、男女模型、自动攻击、移动、闪身、彩色三选卡、大招一至三阶、首波清场到第二波、四件战利品分页、武器架换回旧兵器后再换上新兵器均已操作。另记录一次死亡及正常重开。最终素材包另做了冷启动、战斗和选卡检查，未见控制台错误或警告。未完成浏览器从头到尾五波通关。
- 范围：编辑模式的21,828个几何样本复验通过。近战扇形按墙裁切，完整圆形大招按本版规则可越墙；可见轮廓与伤害查询共用冻结范围。几何回归不能代替真实战斗、GPU显示或手感测试。
- 构建：Unity 6000.3.26f1，0.27.0-preview.1，WebGL 构建成功，0错误、17条构建告警。游戏文件约103.6 MiB；网页导出仅降低远景法线贴图分辨率，保留人物、模型、骨骼和底色贴图。

尚未完成：普通技能多路线、不同种子平衡、完整浏览器五波、Safari/手机、长时间声音耐听性与重玩性。当前怪物只有两套主要轮廓，牛魔王仍复用先锋；专属Boss模型和更丰富的演出仍需制作。奖励只读期间的大招收藏有一处“请先暂停”提示不够准确，返回奖励选择的功能正常。
