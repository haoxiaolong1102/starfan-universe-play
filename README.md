# 小人物逆袭 · 五幕25关试玩

[打开 0.30 网页试玩](https://haoxiaolong1102.github.io/starfan-universe-play/unity-0-30/)。电脑浏览器打开即可玩，无需安装 Unity、插件或登录 Unity 账号。

入口只选姓名与男／女。长棍开局，首关清场后获得长弓和法杖；暂停菜单的武器架可以换装，武器决定攻击方式，已学卡牌保留。WASD 移动，自动攻击，Shift 闪身，Space 大招，Esc 暂停。

本版含五幕25关、三类真实武器攻击、12张适配卡和一种可成长的实体棍阵大招。首次加载约142 MiB，页面显示下载和初始化进度。

当前源码通过304项系统／战斗回归及4项装备模型预览；一次正常公共输入自动游玩完成25关。浏览器实际操作另行验收，不能等同人工或网页完整25关通关。当前仍为试玩版，前期近战上手、信息遮挡、后幕美术及动作专属性需要继续改进。

本仓库仅包含 Unity WebGL 发布产物。素材、音频及字体的实际来源见游戏页面底部署名。
