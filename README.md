# 小人物逆袭 · 首幕五波试玩

[打开 0.27 网页试玩](https://haoxiaolong1102.github.io/starfan-universe-play/unity-0-27/)。电脑浏览器打开即可玩，无需安装 Unity 或登录 Unity 账号。

本版集中验证《月光宝盒》主题山寨中的五波挑战：怪物主动来袭，角色自动攻击；WASD 移动、Shift 闪身、Space 大招、Esc 暂停。成长与战利品使用彩色卡牌，本局已确认的兵器可以从武器架换回。

当前开放长棍及“一棍开天”。其他职业、其他大招和后续电影场景尚未开放。首次加载游戏文件约 103.6 MiB，页面显示下载与初始化进度。

Unity Editor 的单路线五波运行通过；Chrome 已验证开局、战斗、成长卡、首波清场到第二波、装备翻页与换回兵器。详细覆盖及未完成项见[测试记录](unity-0-27/TEST-REPORT.md)。多路线平衡和完整浏览器五波通关仍待继续验证。
