电脑浏览器直接打开，无需安装Unity。入口只选姓名与男／女，武器在局内决定主攻方式。WASD移动，自动攻击，E互动，Q用葫芦，Shift闪身，Space绝招，Esc暂停；兵器架可正常换回已经持有的兵器。

当前单人主线为五个电影灵感世界，每世界4区，共20区。0.33本地正常输入测试从新档走完五世界，7局5胜、保留两次战斗失败，结算后刷新数据一致。完整步骤、测试工具清理故障及范围见报告；历史25关目标不由20区替代。

本版改进中央战斗视野、卡片与武器反馈、中断恢复页中文和清底。门楼屋顶遮挡、边缘HUD可读性、电影美术联想与下载体积仍需继续改进；首玩约65.4MB，当前为试玩版。
