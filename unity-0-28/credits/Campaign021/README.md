# 小人物逆袭 0.21 道具卡图与装备特效

本批图片是项目现有闭合 3D 道具在独立 Unity Preview 场景中的离线拍摄，共 120 张，每张 384 × 384 像素；不是电影剧照、官方海报或演员肖像。5 章分别组合宝盒与棍、斧与古琴、厨具与肉丸、足球与队长信物、金枪与飞刀等物件。18 种技能与 6 种大招分别拍摄；品质框、等级、标题与属性由运行时 HUD 独立绘制，没有烘进图里。主副物件按实际合并 bounds 的八个角点拟合，四边各预留至少12%画幅安全区。缺少确切模型的紫青剑、铁环、饭碗、蒸笼、恐龙头骨等只使用机制意象，不称作精确的电影道具复制品。

拍摄使用只存在于临时预览场景的独立工作室材质，保留原网格、基础贴图、材质色、金属与发光信息，以明确的前侧光、补光和轮廓光呈现体积；线性预览目标在写入 PNG 时显式转为显示用 sRGB，不更改原材质。拍摄只读取现有 Fan019 / Campaign018 / Campaign020 / Film01 等资产；不修改原始模型、骨架、材质或源纹理。新 PS 读取既有 VFX 纹理的独立副本，尾带的灰度遮罩在新副本中导入为 alpha。原始来源及许可证继续随包提供，见既有 Source / Campaign020 / Fan019 署名记录。此说明不创建任何电影 IP 授权。

manifest.json 记录本次生成的真实 PNG 路径、尺寸、字节数、SHA256，以及使用的每个既有 prefab 和 VFX 纹理路径与 SHA256。完整 3D 网格与原始许可链仍由既有源资产记录负责；prefab 的 SHA 并不替代其所有依赖的许可清单。

生成工具：Assets/StarFan/Editor/SF021CardArtBuilder.cs、SF021ArtBuilder.cs。前者使用 PreviewRenderUtility 与独立预览场景，结束后清理相机、灯与临时物件；后者仅生成 Presentation021 独立资源。照片式道具预览不是实战截图，实战可读性与性能测试见本版本测试报告。
